# kzp_lab67 — розклад занять засобами Python

Лабораторна робота № 6 з курсу «Кросплатформні засоби програмування»,
варіант **№ 3 — Розклад занять**.

## Призначення

Пакет `kzp_lab06` читає CSV-файл розкладу занять, перетворює текстові поля на
типізовані значення, будує звіт за списками, словниками й множинами та
записує його в текстовий файл. Вхідний файл не змінюється.

## Формат вхідних даних

CSV у UTF-8, роздільник — кома, перший рядок — заголовок із машинними назвами
стовпців. Читання йде за назвами, тож порядок стовпців не важливий.

```
day,period,room,subject,teacher
Понеділок,1,101,Програмування,Олексів М. В.
Вівторок,1,215,Кросплатформні засоби,Рудик Ю. І.
Середа,1,98,Бази даних,Коваленко О. П.
```

| Поле | Тип | Правило |
|------|-----|---------|
| `subject`, `teacher`, `day` | текст | непорожні |
| `period` (номер пари), `room` (аудиторія) | ціле | більше 0 |

Поле з комою, лапками чи переносом рядка береться в лапки, а лапки
подвоюються. Файл лише із заголовком — коректний порожній вхід, повністю
порожній файл — помилка.

`data/input.csv` — це експорт лабораторної № 5 (`--export`): три записи з
вхідного файла без змін; замінено лише рядок заголовка на англомовні назви.

## Структура пакета

```
src/kzp_lab06/
├── __init__.py    # публічний API
├── errors.py      # DataError
├── loader.py      # читання CSV (csv.DictReader) і перетворення типів
├── analysis.py    # відбір за днем, словник, множина, summarize(*args, **kwargs)
├── reporting.py   # формування й запис звіту
└── cli.py         # аргументи командного рядка, коди завершення
tests/             # pytest
data/input.csv     # вхідні дані
```

## Команди запуску

Потрібен Python 3.11 або новіший.

```
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install -e ".[dev]"

python -m kzp_lab06.cli data/input.csv reports/summary.txt
python -m kzp_lab06.cli data/input.csv reports/summary.txt --day Середа
kzp-lab06 data/input.csv reports/summary.txt
```

Аргументи: вхідний CSV, вихідний звіт, необов'язковий `--day` (за
замовчуванням «Понеділок»).

| Код | Значення |
|-----|----------|
| `0` | успіх |
| `1` | помилка даних (`DataError`) |
| `2` | хибні аргументи |
| `3` | помилка файла |

Повідомлення про помилки виводяться в stderr.

## Перевірка

```
python -m pytest
ruff check .
ruff format --check .
python -m build
```

Wheel у чистому середовищі (Ubuntu і macOS):

```
python3 -m venv .venv-wheel
.venv-wheel/bin/python -m pip install --no-deps dist/kzp_lab06-1.0.0-py3-none-any.whl
.venv-wheel/bin/python -m kzp_lab06.cli data/input.csv reports/wheel-summary.txt
```

На Windows замість `.venv-wheel/bin/python` використовується
`.venv-wheel\Scripts\python`.
